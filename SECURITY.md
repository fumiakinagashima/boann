# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in Boann, please report it privately rather than filing a public GitHub issue.

- Preferred: open a [GitHub Security Advisory](https://github.com/fumiakinagashima/midleton/security/advisories/new) for this repository.
- Alternatively, email alcogyinc@gmail.com with details and steps to reproduce.

Please include as much detail as you can (affected version/commit, reproduction steps, potential impact) so the issue can be triaged quickly. We'll acknowledge reports as soon as possible and keep you updated as a fix is developed.

Please do not publicly disclose the issue until a fix has been released.
